# VoxDirector

Audio samples for VoxDirector: Learning Speech-Centered Audio Scenes from Structured Supervision.

The VoxVAE tab compares originals with V14 z96 reconstructions (48 kHz mono, 25 Hz latents, 96 dimensions; checkpoint step 202000). Speech, Music and General Audio each contain the five examples with the lowest waveform MAE in the reviewed pool. Singing is included in Speech; mixed examples follow their dominant audible content. Open `/?demo=voxvae#samples` for a direct preview.
